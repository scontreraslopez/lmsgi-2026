# Lenguajes de Marcas y Sistemas de Gestión de Información (LMSGI)

Materiales del módulo **0373 Lenguajes de Marcas y Sistemas de Gestión de Información**, primer curso de **Desarrollo de Aplicaciones Multiplataforma (DAM)**, modalidad **semipresencial**, curso **2026/27**.

El módulo recorre el tratamiento de la información con lenguajes de marcas: fundamentos de los lenguajes de marcas y de la web, estructura y semántica con HTML, formularios, presentación con CSS, almacenamiento de información en XML y JSON con su validación (DTD y XML Schema), consulta y conversión con XPath, XSLT y XQuery, interactividad en el navegador con JavaScript y manipulación del DOM, y la instalación, configuración y uso de sistemas de gestión de información empresarial.

## Entorno de trabajo

- Aules como aula virtual;
- **Visual Studio Code** como editor principal, con extensiones como Live Server o Live Preview y abreviaturas **Emmet**;
- navegador web y sus **herramientas de desarrollo**;
- validadores del **W3C** para HTML y CSS, y validación de XML contra **DTD** y **XML Schema**;
- procesadores de **XPath**, **XSLT** y **XQuery**;
- **JavaScript** en el navegador para la interactividad y la manipulación del DOM;
- **XAMPP**/**Docker** y **WordPress** para las unidades de sistemas de gestión de la información.

Las herramientas concretas son elecciones del curso y pueden adaptarse al entorno de cada estudiante. Como documentación de referencia usaremos principalmente **MDN Web Docs**, con **W3Schools** como apoyo. Los materiales se redactan de forma que puedan seguirse con otros editores y navegadores.
